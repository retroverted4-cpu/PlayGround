## Bloon Patrol

A complete, self-contained 40-wave tower defense game built with vanilla HTML, CSS, and JavaScript. Pop balloons before they reach the gate, earn cash, and upgrade nine monkey towers across Sunny Meadow.

### Play

Serve the folder with any static web server and open `index.html`:

```bash
python3 -m http.server 3002
```

Then visit <http://localhost:3002>.

### Controls

- Click a tower in the Armory, then tap the grass to build it.
- Click a placed tower for targeting, upgrades, and selling.
- `1`–`9` select towers, `Space`/`Enter` starts a wave, `P` pauses, `F` changes speed, `M` mutes, `U` upgrades, `S` sells, and `Esc` cancels or deselects.
- On touch screens, tap the selected tower card again to cancel placement.

Everything is generated at runtime: graphics are drawn on canvas and sound is synthesized with WebAudio, so there are no external assets to download.
